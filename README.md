# 🅿️ Sistema SaaS de Gestão de Estacionamento

Solução SaaS (Software as a Service) desenvolvida para automatizar e otimizar o controle operacional e financeiro de estacionamentos e garagens comerciais.

🌐 **Acesse a Aplicação Online:** [Estacionamento SaaS - Vercel](https://estacionamento-saas-ashy.vercel.app/)

---

## 📌 Sobre o Projeto

O **Estacionamento SaaS** é uma plataforma moderna e responsiva projetada para gerenciar o fluxo de veículos, cálculo de permanência e métricas operacionais. O sistema utiliza uma arquitetura híbrida que combina microsserviços em Python, automação via Google Apps Script e um design construído com apoio de IA Generativa e agentes inteligentes.

### 🚀 Principais Funcionalidades

- **Controle de Entrada e Saída:** Registro simplificado de veículos com cálculo automático de tarifação por permanência.
- **Painel de Métricas & Relatórios:** Visualização dinâmica dos indicadores de faturamento e ocupação de vagas.
- **Integração de APIs:** Comunicação fluida entre o front-end e os serviços de backend/banco de dados.
- **Design Inteligente & Responsivo:** Interface limpa, intuitiva e acessível otimizada para múltiplos dispositivos.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end & UI/UX:** HTML5, CSS3, JavaScript (estruturado com apoio de Agentes de IA)
- **Back-end & Automações:** **Google Apps Script** & **Python APIs**
- **Hospedagem & Deploy:** Vercel Community Cloud
- **Versionamento:** Git & GitHub
